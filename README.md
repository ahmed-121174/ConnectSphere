# ConnectSphere

A simple social media like desktop application built with **Python** and **Tkinter** for the GUI. ConnectSphere allows users to register, manage profiles, follow others, create posts, like and comment on posts and more all through a clean, modular design.

---

## 🧠 Features

### 👤 User Management
- Register and authenticate securely
- Update bio and change password
- Follow and view followed users

### 📝 Post Management
- Create, view, edit, delete posts
- Like, unlike, comment, and share posts
- Retrieve posts and comments efficiently

### 🔐 Session Management
- Log in and log out
- Track active sessions

---

## 🛠️ Tech Stack

- **Language:** Python
- **GUI:** Tkinter
- **Data Storage:** Plain text files (`.txt`)
- **Architecture:** Modular (User, Post, Session Managers)

---

## 📈 System Design

### 🏗️ Architecture
- **UserManager**: Handles authentication and user data
- **PostManager**: Manages all post operations
- **SessionManager**: Controls login sessions

### 🖼️ GUI
- Scrollable post feed
- Buttons and fields for interaction
- Profile management options

---

## 📋 Requirements

- Python 3.x
- Tkinter

---

## 🚀 Getting Started

1. **Clone the repo:**
   ```bash
   git clone https://github.com/ahmed-121174/ConnectSphere.git
   cd ConnectSphere
````

2. **Run the app:**

   ```bash
   python main.py
   ```

## 📌 Notes

* All user and post data is stored locally in `.txt` files.
* Security is maintained by storing passwords securely and managing session files.
